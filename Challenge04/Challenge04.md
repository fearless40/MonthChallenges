# Challenge 4
The goal is to write a game of battleship. Single player only. Plan to write the basic rules of the game. 
* Rules
    * A grid that is 10x10 cells wide 
    * Ships that are 2 to 5 cells long
    * Ships cannot cross over each other
    * Ships must not extend beyond the edge of the map
    * A player can position their ships wherever they want on the map as long as it does not violate the other rules
    * A player takes a turn guessing at the location of the enemy ships
    * A player is informed if they hit a ship
    * A player is informed if they sunk a ship and which ship that they sunk 
    * A game is won when all the opposing players ships are all sunk 
The other player in this instance will be an AI player that was developed in Challenge 3. 
There are no restritions on the UI. 
This challenge does not contain networking. That will be added in Challenge 5. 


## Command line interface
Optional command line. When running the program a game should be played.
